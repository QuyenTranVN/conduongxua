# Images

Drop your own licensed photographs here. Until a file exists the app draws a
tinted placeholder in its place, so nothing breaks.

    teachers/
      chah.jpg  jayasaro.jpg  brahm.jpg  sumedho.jpg  pasanno.jpg
      mun.jpg   thanissaro.jpg  user.jpg
      → square, 400×400 or larger

    covers/
      natural-mind.jpg  attachment.jpg  uncertainty.jpg
      peace.jpg  middle-way.jpg  letting-go.jpg
      → square, 800×800

    scenes/
      splash.jpg     → portrait, 1200×2000
      session.jpg    → portrait, 1200×2000

Filenames are set in `src/data/content.js` — change them there if you prefer
different names.

## Before you ship

Photographs of named monks are pictures of real people. Get permission from the
monastery or the copyright holder before publishing. Most forest monasteries
will say yes if you write and explain the project; several publish image
libraries specifically for free distribution. Ask in the same email you use to
request the audio.
